# HanoiFX
## Towers of Hanoi visualizer in your terminal
Step by step execution. No rush. Witness the recursion. With random colors.

# Usage
```shell
git clone https://github.com/skyprincegamer/hanoifx
cd hanoifx
cargo run --release -- <NUMBER_OF_DISCS>
```
# Example
```shell
# To solve with 10 discs
cargo run --release -- 10
```
